1.Install Node.js
Download LTS from nodejs.org, install it. 
Verify with `node -v` and `npm -v` in terminal.

2.Install VS Code + Claude CodeInstall VS Code
if you don't have it. Install Claude Code 
(`npm install -g @anthropic-ai/claude-code`), then run 
`claude` inside your project folder once it exists.

3.Scaffold the projectIn terminal: 
`npm create vite@latest max-office-smash -- --template vanilla`, 
then `cd max-office-smash && npm install three`. 
Run `npm run dev` to confirm it loads a blank page in the browser.

4.Create a GitHub repoMake a new empty repo on GitHub, 
then in your project folder: `git init`, 
`git remote add origin <url>`, `git add .`, `git commit -m init`, 
`git push -u origin main`. Do this now, before heavy coding, 
so you're not fighting Git later.

5. Prompt 1 — world + truck + camera"Set up a three.js 
scene in this Vite project: a lit room (floor + 4 walls, 
box geometry, neutral colors), a box representing a truck 
with WASD-controlled acceleration/turning and friction, 
and a camera that smoothly follows behind it. Split 
into scene.js, truck.js, input.js, wired in main.js. 
Use requestAnimationFrame for the game loop."

Prompt 2 — office props"Add office objects to the room: 
desks, monitors, chairs, printers as simple box/cylinder 
geometry with distinct colors, scattered around the floor. 
Put this in office.js and destructible.js, each object 
storing a point value."

Prompt 3 — collision + destruction"Add collision 
detection between the truck and office objects 
(simple bounding-box check in collision.js). 
On hit, the object should react — fly/knock away 
and disappear — and award its point value to a running score."

Prompt 4 — timer + score UI + game over"Add a gameState.js 
that tracks a countdown timer (say 60 seconds) 
and current score, plus a ui.js HTML overlay showing both live. 
When time runs out, show a game-over screen with final 
score and a restart button that resets everything."
