# 🛠️ Max Farm Smash — Setup Guide

Get the game running on your computer in a few steps.

---

## 1. Install what you need

- [Node.js](https://nodejs.org) (LTS version)
- [VS Code](https://code.visualstudio.com) *(optional, but nice to have)*

## 2. Get the code

```bash
git clone https://github.com/casgomp/-max-office-smash.git max-office-smash
cd max-office-smash
```

## 3. Install & run

```bash
npm install
npm run dev
```

Open the link it gives you (usually `http://localhost:5173`) in your browser — the game should load.

## 4. Multiplayer

Multiplayer works right out of the box — there's nothing extra to set up.
